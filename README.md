\# Telehealth Survey Analysis



This repository contains Python analysis code developed as part of my MSc Digital Health thesis: Designing a Defense-in-Depth Framework for Telehealth Resilience.



\## Project Overview

The purpose of this project is to process, clean, and analyze survey data collected during my thesis research. It automates the data preparation workflow, performs inferential statistical testing, and generates visualizations to identify trends in telehealth resilience, availability, and safety.



\## Repository Structure

&#x20;  `survey\_analysis.py`: Cleans data and generates descriptive visualizations (histograms, bar charts, heatmaps).

&#x20;  `inferential\_analysis.py`: Performs statistical tests to evaluate survey hypotheses and correlations.

&#x20;  `requirements.txt`: Lists all necessary Python packages.



\## Key Features

\- Data Cleaning: Handles missing values and structures raw survey responses from CSV files.

\- Descriptive Analysis: Aggregates and counts survey responses to extract key metrics.

\- Inferential Statistics: Conducts statistical testing to identify significant relationships in the data.

\- Data Visualization: Generates histograms, bar charts, and heatmaps to visualize response distributions.



\## Privacy Note

To protect participant privacy and comply with research ethics, the raw survey dataset is not included in this repository.
